# دفتر التحضير - Frontend فقط

نسخة موبايل أولًا لإدارة حضور الموظفين، مبنية بـ HTML وCSS وJavaScript بدون Backend.

## الملفات
- `index.html`: التطبيق والشاشات والمنطق والتخزين والتقارير.
- `manifest.webmanifest` و`sw.js`: أساسيات تثبيت التطبيق (PWA) وكاش ملفات الواجهة.
- `assets/`: أيقونات التطبيق.

## التشغيل
1. ارفع محتويات هذا المجلد إلى استضافة Static مثل Vercel أو Netlify.
2. افتح رابط HTTPS من الهاتف.
3. أدخل رمز التفعيل التجريبي: `PETER-2026` (يُستخدم مرة واحدة على المتصفح).
4. أنشئ حساب المشرف ثم أضف الموظفين.
5. من «التقارير الشهرية» اختر الشهر ثم صدّر Excel أو افتح الطباعة واحفظ PDF.

يمكن أيضًا تشغيله محليًا من خلال خادم محلي بسيط مثل `python -m http.server 8000` ثم فتح `http://localhost:8000`.

## تخصيص رابط المطور
- رابط اسم المطور في تذييل الصفحات مضبوط حاليًا كعنصر جاهز؛ لإضافة الوجهة لاحقًا، ضع الرابط في الثابت `DEVELOPER_LINK` أعلى JavaScript داخل `index.html`.

## ملاحظات مهمة قبل البيع
- غيّر `ACTIVATION_CODE` أعلى كود JavaScript في `index.html` لكل نسخة أو عميل. هذا التفعيل واجهة محلية فقط وليس نظام ترخيص آمنًا لأنه Frontend فقط.
- بيانات الحساب وكلمة المرور والموظفين وسجلات الحضور تُحفظ محليًا في `localStorage` على نفس المتصفح والجهاز. لا توجد مزامنة أو صلاحيات/حماية حقيقية من جهة الخادم.
- استخدم زر «تصدير نسخة احتياطية» بصورة دورية، خصوصًا قبل مسح بيانات المتصفح أو تغيير الهاتف.
- مكتبة Excel (ExcelJS) موجودة محليًا في `vendor/` فالتصدير يعمل بدون إنترنت.
- الصور: ضع `hero.jpg` (الرئيسية) و`login.jpg` (شاشة الدخول) داخل `assets/photos/`؛ لو غير موجودة يظهر تدرج لوني بدلها.
- على بعض الهواتف، سيظهر نظام المشاركة بدل التنزيل المباشر. اختر «حفظ في الملفات» على iPhone أو مجلد التنزيلات على Android.

## قواعد التحضير
- التعديل متاح على تحضير اليوم الحالي فقط؛ أي يوم سابق أو قادم للعرض فقط.
- التغييرات مسودة حتى الضغط على «اعتماد التحضير» وإدخال كلمة المرور. بعد الاعتماد يلزم «تعديل» ثم اعتماد جديد بكلمة المرور.
- لو انتهى اليوم قبل الاعتماد، تُحفظ المسودة كما هي ويُغلق اليوم تلقائيًا.
